Issue #41 · Shelf Map button graphics

Four ways to draw the Shelf Map button

The Shelf Map button sits inside Ex Libris's own Get It controls, so it is judged against their icon set — not on its own. Here are four treatments, each rendered at 1:1 inside a replica of the real location card, in English and Hebrew. Pick one.

Starting point

What ships today

Issue #41 opens on the glyph: map is the folded-paper Google-Maps icon, and it reads as geography rather than where this book physically sits. That is true. But measuring the live button turned up two problems the issue does not mention, and they are the ones a patron actually notices first.

Colour The button is hard-coded to #1976d2, Material's default blue. Every native control beside it uses the theme token --sys-primary = #3f608a. Against the card's #f3f3f3 ground that hard-coded blue measures 4.15:1 — under the 4.5:1 WCAG AA floor for normal text. The theme colour measures 5.82:1 and passes.
Shape It is a 4px-radius outlined rectangle among fully-rounded 9999px pills with no border. Two different button languages, 30 pixels apart.
RTL The SCSS applies flex-direction: row-reverse under RTL on top of the direction flip the browser already performs. Measured on the live Hebrew page, the icon lands after the label — x 25–45px for the glyph against 43–101px for the text — so the icon leads in English and trails in Hebrew. Whichever option is chosen, that rule comes out.

Common ground

What all four options change

The options differ only in the glyph and how loud the button is. All four take the same three corrections, so those are not part of the choice:

Colour follows the token. #1976d2 → var(--sys-primary). Fixes the contrast failure and survives the pending recolour in issue #29 without a second edit.

Shape becomes a pill. border-radius: 9999px, padding: 0 16px, height: 40px — the same geometry as View Items.

The RTL override is deleted. The icon leads in both languages. None of these glyphs is directional, so none of them mirrors.

Recommendation

Take B, unless the glyph has to do the talking

B (Pin it) is the pick. The Shelf Map button is a feature the library added deliberately and that patrons have no reason to expect, which argues against A's total assimilation — but today's button buys its prominence by clashing, using a colour and a shape that belong to no other control on the page. A tonal pill is exactly the Material 3 device for one emphasised action among plain ones: it is louder than everything around it while being built entirely from the theme's own tokens. And a pointer answers #41's actual complaint more directly than a bookshelf does, because the objection was to folded map, not to the idea of location.

Take C instead if you would rather the glyph carry the meaning on its own — it is the only option that says "book" and "place" in one mark. It is also the only one that needs a drawing someone is willing to own; the sketch here is a starting point, not a deliverable.

A and D are the safe floors. Both are correct, both are free, and both accept that the button stops standing out. If the recolour and the pill shape alone turn out to be enough, A is the smallest change that is defensible.

One question still open, from #41: is this driven by a specific complaint — did someone say the icon confused them or that they could not find the button — or is it a polish pass? If patrons could not find it, B is the answer and prominence is the whole point. If patrons found it and misread it, C is the answer and the glyph is the whole point. That answer also decides whether the label wording is in scope.

Once you have picked

What changes in the code

Two files, plus a registry call if you take C. The aria-label stays exactly as it is in every option — the icon never becomes the only carrier of meaning.

/* cenlib-map-button.component.scss */
.cenlib-map-button {
-  border-radius: 4px;
-  padding: 6px 16px;
-  min-height: 36px;
+  border-radius: 9999px;
+  padding: 0 16px;
+  height: 40px;
+  gap: 8px;

  &.mat-mdc-outlined-button {
-    border-color: #1976d2;
-    color: #1976d2;
+    border-color: var(--sys-primary);
+    color: var(--sys-primary);
  }
}

// delete outright — the browser already flips the row under RTL,
// and this second flip is what puts the icon after the label in Hebrew
-:host-context([dir='rtl']) .cenlib-map-button { flex-direction: row-reverse; }
<!-- cenlib-map-button.component.html — option B -->
<mat-icon>maplocation_on</mat-icon>

<!-- option C: registered once in the component constructor -->
iconRegistry.addSvgIconLiteral(
  'tau-shelf-pin',
  sanitizer.bypassSecurityTrustHtml(SHELF_PIN_SVG)   // inlined, never fetched
);

A tonal fill for B means dropping mat-stroked-button for mat-flat-button with background: var(--sys-primary-container), rather than adding a background to an outlined button and leaving a stray border behind.
