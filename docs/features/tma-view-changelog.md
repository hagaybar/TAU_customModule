# TMA view — change log

What has changed on the TMA view (`972TAU_INST:TMA_NDE` now, `972TAU_INST:TMA` after cutover),
newest first. One entry per change that a patron or the archive's owners could notice, whether
it was made in this repository or in the Alma Back Office.

**Why this file exists.** The view's history was split between the repository (dated comments
next to each CSS rule, git history) and the Back Office (screenshots, memory). Neither one alone
says *what the view looks like and why*. This file is the index that joins them; the reasoning
for each change stays in the comment beside its code, so it is not repeated here.

**How to add an entry.** Date, what changed, who asked, where it lives (file or Back Office
screen), and the PR. Back Office changes get an entry too: they are invisible in the repository,
and the package often depends on them.

The view: *The Reconstructed Trademarks and Patents Registry of Mandate Palestine (1922–1948)*.
English is the default language; the content family is `tma`, under
`src/assets/views/tma/` and `src/app/views/tma/`. See *Per-view content* in `CLAUDE.md`.

## 2026-10-06

- **Loading animation is now NDE's ring orbit, in brown.** *Repository.* Requested by the
  owner: the same loader as the NDE view, recoloured to TMA's brown theme. It replaces the
  registry stamp. Dark dot `#4e4541` (the theme's warm dark brown), ring and diamond
  `#a8968c`. Verified in the live TMA_NDE spinner, by serving the new file in place of the
  deployed one, before upload.
  `src/assets/views/tma/images/loadingAnimations/LoadingAnimationJson.json`, generated by
  `docs/assets/TMA/make-loading-ring-orbit.py` · PR pending.

## 2026-10-05

- **Loading animation drawn at full size.** *Repository.* Complaint that the loader is too
  small. The host's spinner hardcodes `transform: scale(0.5)` on the Lottie box, so every
  animation shows at half its 300x90 canvas; CSS now overrides it to full size (2x — the
  stamp goes from ~29px to ~58px wide). Test on TMA_NDE first; NDE has the same problem.
  `src/assets/views/tma/css/custom.css` (fence "loading animation at full size") · PR pending.

- **Landing-page cards point at the new dedicated search tabs.** *Back Office + repository.*
  The Back Office now has separate `TRADEMARK` and `PATENT` search tabs and scopes. Both
  cards (English and Hebrew) open those tabs, not the single `TMA` scope narrowed by a
  resource-type filter. Counts are unchanged: 7,903 trademarks and 3,557 patents for the query
  "application". The `vid` rewrite in `custom.js` is untouched, so the links still follow the
  view at cutover.
  `src/assets/views/tma/homepage/homepage_{en,he}.html` · PR #78.

- **"Links" panel hidden on the full record display.** *Repository.* Requested by Oren. The
  Back Office has no switch for it, and hiding only the label left an empty bordered strip,
  so CSS hides the whole panel, including its divider lines. Every record showed "No links are
  available for this record".
  `src/assets/views/tma/css/custom.css` (fence "hide the Links section") · PR #77.

  *Deploy note:* the first package uploaded that day (`b34f250`, 12:58Z) carried only the
  card change, because the two PRs were built from separate branches. The panel stayed visible
  until a package containing both went up. Before uploading, check that one package holds
  every change you expect.

## 2026-09-15 — first NDE package

The view had no customization package before this; the conversion from classic Primo to NDE
was built here and merged as PR #71 (one repository, content chosen per view family).

- **Landing page owned by the package.** In the Back Office, the Landing Page
  "Enable configuration" box is **unchecked**, which makes the host fetch our
  `homepage_{en,he}.html` and `homepage.css`. Ticking it brings the native landing page
  back, and our HTML stops being requested.
- **Two homepage cards**, trademarks and patents, mirroring the classic view.
- **Banner background:** Hila's patent-drawing strip replaces the stock bookshelf photo
  (`custom.css`, fence "banner background").
- **Language selector and sign-in hidden.** The view is English-only and public. Hebrew is
  still reachable with `?lang=he`.
- **"Sign in to get more results" notification hidden**, since there is no way to sign in.
- **Footer:** the university policy line carried over from the classic view.
- **Logo:** Hila's wordmark, with the classic view's corner "stamp" marks restored.
  Regenerated by `docs/assets/TMA/make-logo.py`; see `docs/assets/TMA/README.md`.
- **Loading animation:** a registry-stamp animation replaces the host's default dots
  (`docs/assets/TMA/`).
- **No custom components.** NDE's external search, shelf map and collection filter mean
  nothing for this archive; `src/app/views/tma/component-map.ts` is empty on purpose.
