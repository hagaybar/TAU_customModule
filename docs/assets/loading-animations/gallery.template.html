What constrains the choice

One file ships. Primo fetches assets/images/loadingAnimations/LoadingAnimationJson.json from the customization package and falls back to its own purple dots on a 404. Whichever candidate wins is copied over that name.

NDE and NDE_TEST share it. They are one view family in the repo, so the winner is also what the next production build ships. NDE_TEST gets it first, and alone, because every deploy is a manual upload.

The colours are baked in. A custom animation does not follow the view's --sys-primary theme colour — it carries its own. These use the blue ramp already shipped today, plus the azure sampled from the DaTA logo.

The stages stay white in dark mode on purpose: the Primo boot screen paints white before the theme stylesheet lands, so that is the ground a patron actually sees.
