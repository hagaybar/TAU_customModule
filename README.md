# gh-pages

This branch is the GitHub Pages site for `hagaybar/TAU_customModule`. It is **published to the
open web with no sign-in**, so only put things here that are fine for anyone to read.

It is deliberately an orphan branch — it shares no history with `main` and contains none of the
source tree. That is the point: Pages serves whatever is on this branch, so keeping it to a
handful of generated review pages means nothing else in the repository becomes a website.

## What is here

| Path | Source | Generated by |
|---|---|---|
| `index.html` | hand-written | — |
| `loading-animations/index.html` | `docs/assets/loading-animations/gallery.standalone.html` on `main` | `docs/assets/loading-animations/generate.mjs` |

## Updating a page

Regenerate it on the source branch, then copy the built file here and push:

```bash
node docs/assets/loading-animations/generate.mjs
# then copy docs/assets/loading-animations/gallery.standalone.html
# over loading-animations/index.html on this branch
```

Do not edit the copies on this branch by hand — the next regeneration silently discards the edit.

`.nojekyll` stops GitHub running the files through Jekyll, which would otherwise mangle any path
beginning with an underscore.
